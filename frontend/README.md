# To-Do Frontend (React + Vite)

Minimal React "Hello, world" application to start the front-end for the to-do app.

Quick start (PowerShell):

```powershell
npm install
npm run dev
```

Then open the URL printed by Vite (usually http://localhost:5173).

Notes:
- Requires Node.js (v16+ recommended). If you use yarn or pnpm, you can replace npm commands accordingly.
- After this works, we can add to-do list components, state management, persistence, tests, etc.
